# staketracker

Library to detect and track stakes on glaciers


## Installation

We recommend you use uv: https://docs.astral.sh/uv/getting-started/installation/

```
uv sync
source .venv/bin/activate
```

If you prefer to use anoother package and virtual env manager

```
pip install .
```

## Run

You should have a sample of pictures in `photo_fixe_linceul`

```
python sobel.py
```
